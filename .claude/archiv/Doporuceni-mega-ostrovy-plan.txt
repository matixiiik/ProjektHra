Pokračování příběhu — mega ostrovy
Context

Hráč doplaje na příběhový mega ostrov (storyStep 2 → 3) a dostane jen hlášku "někdo tu už kopal". Na ostrově se nedá nic dělat — je to jen země + obelisk (MegaIslandMarker). Cíl: udělat z toho reálný úkol a rozvést příběh do krátkého uzavřeného oblouku přes 3 tematicky odlišné mega ostrovy, s přepady na moři mezi nimi, aby to nebylo pořád stejné.

Rozhodnutí uživatele:

Úkol na ostrově: probojovat se přes obránce → uprostřed trezor, který se otevře přes puzzle (5–20 min čistého hraní, komplexnější ale řešitelné).
V trezoru není poklad, ale vzkaz od soka.
Sok = někdo ze sokovy minulosti starého námořníka; identita se odhaluje postupně přes 3 ostrovy; finále = setkání obou stařešinů po letech, teprve tam se odhalí kdo to je.
Rozsah: všechny 3 ostrovy + přepady + finále, ale po malých kouskách (do maturity ~6 měsíců).
Strážci ostrova 1: nový stacionární typ nepřítele (zbraně — mušketa apod. — se doladí později, v1 stačí základ).
1. Příběhový oblouk
Ostrov 1 — "Pevnost staré posádky"

Opevněný úkryt sokovy staré posádky. Zarostlé, děla, uzamčený trezor.

Připlutí → 2–3 ostrovní děla (HostileIslandCannon) + 1 hlídkující pirátská loď po tobě pálí. Sejmeš je z lodě. Pak je moře čisté a doplaješ k molu.
Pěšky → nový typ nepřítele: stacionární strážci (LandGuard) — stojí na místě, když jsi blízko, pálí po tobě. (v1: koule jako dělo; v2: mušketa)
Trezor uprostřed, zamčený. Puzzle: po ostrově je ~6 kamenných tabulek s vodítky (hádanka / symbol). Přečteš je (E), z nich vydedukuješ 4-symbolový kód a zadáš ho na trezoru. Špatně → "X ze 4 správně". Chodíš po velkém ostrově, čteš, luštíš → 5–20 min.
Trezor se otevře → prázdný, jen vzkaz soka: "Přišel jsi pozdě, [starý příteli]. Našel jsem to první. Jestli to fakt chceš, hledej mě dál. — [iniciála]"
náznak, že sok zná starého námořníka jako kapitána.
Doma (dialog s námořníkem, storyStep 4): pozná rukopis, zmlkne, dá souřadnice ostrova 2 — ale neřekne kdo to je. → megaIndex++, nový mega ostrov, waypoint, storyStep 2.
Přepad mezi 1 a 2

Zhruba v polovině trasy k ostrovu 2 → 2 piráti + toast "Tihle na tebe čekali…". Jednorázově (ambush1Done v save).

Ostrov 2 — "Hřbitov lodí"

Vraky, mělčiny, jiná atmosféra (víc průzkum, míň boj).

Kolem ostrova loď ducha (ship-ghost) — mini-boss.
Trezor = zpola zahrabané lodní podpalubí. Jiný puzzle: najdeš 3 kusy roztržené mapy ve 3 vracích (kopeš u nich — jako mega quest dig), složíš je, výsledek = poloha / kód do podpalubí.
Uvnitř sokův nedávno opuštěný tábor. Druhý vzkaz — teď víc: sok viní námořníka z něčeho (ztroskotání / smrt / opuštění). Beze jména, ale je to osobní.
Doma: námořník otřesený, přizná "byl jsem tam kapitán… něco se stalo". Souřadnice ostrova 3.
Ostrov 3 — "Kde to začalo" (sok je tam)

Není to poklad — je tam sok.

Sokova loď hlídá příjezd — boss fight (velká loď).
Vylodíš se. Sok je tam jako NPC (postavička jako námořník, jiný design).
Finální konfrontace: "poklad" = něco malého a osobního (lodní zvon / sokův deník / jméno vyryté do kamene). Případně žádné zlato — smíření.
Setkání: přivedeš soka zpět k námořníkovi. Dva staří lidé po desítkách let. Odhalení kdo sok je. Smíří se (možná volba).
Odměna: unikátní trvalý bonus + storyDone.
2. Sdílená infrastruktura (postavit první)
GameData (nová pole, POUZE na konec — serializují se do save; sdílená P1/P2)
public int  megaIndex;      // 0 = ostrov 1, 1 = ostrov 2, 2 = ostrov 3
public int  megaTask;       // postup na aktuálním ostrově: 0=přijel,1=obrana padla,2=trezor otevřený,3=hotovo (vzkaz vzat / finále)
public int  megaCode;       // rozdělaný stav puzzlu trezoru (zadané symboly, zakódováno)
public int  megaCluesMask;  // které tabulky s vodítky už hráč přečetl (bity)
public bool ambush1Done;
public bool ambush2Done;
public bool storyDone;
MegaIslandMarker = "mozek ostrova"

Dnes jen staví obelisk. Rozšířit:

public static MegaIslandMarker Instance (Awake) — jako ChestManager/StoryNpc, odůvodnění: jeden na hru, musí být dosažitelný z PlayerController.
Start(): obelisk (vždy) + podle grid.gameData.megaIndex zavolá BuildFortress() / BuildWreckGraveyard() / BuildConfrontation().
Deterministické pozice obsahu z storyIslandX/Y + jednoduchý hash (žádná náhoda za běhu, ať to po loadu vypadá stejně).
Update(): hlídá megaTask — když jsou všechna děla + strážci zničení, megaTask 0 → 1 + toast. (Děla volají CombatDirector.OnIslandCannonDestroyed → marker si drží počítadlo, nebo skenuje FindObjectsByType.)
public bool TryInteract(int x, int y, int playerIndex) — marker zná světové pozice obelisku / tabulek / trezoru / vzkazu a testuje Chebyshev(hráč, cíl) ≤ 1:
obelisk → ukáže nápovědu k puzzlu
tabulka → přečte vodítko, nastaví bit v megaCluesMask
trezor (megaTask == 1) → otevře IMGUI zadávání kódu; správně → megaTask 2, objeví se vzkaz; špatně → "X ze 4"
vzkaz (megaTask == 2) → ukáže text soka, megaTask 3
Hák interakce

V PlayerController.TryInteractAdjacentBuilding() (skenuje 4 sousedy, pořadí StoryNpc → Lighthouse → Chest → shopy) přidat JEDEN řádek na začátek: if (MegaIslandMarker.Instance != null && MegaIslandMarker.Instance.TryInteract(tx, ty, playerIndex)) return true;

Umístění dalšího ostrova

Stejný mechanismus jako StoryNpc.GiveToSailor(): nová metoda StoryNpc.GiveNextIslandCoords() — megaIndex++, megaTask = 0, megaCluesMask = 0, megaCode = 0, gridManager.PlaceMegaIsland(sx, sy) (daleko, deterministicky), hasWaypoint = true, storyStep = 2.

StoryNpc dialog
BuildDialogForStep() case 3: text závisí na megaTask — dokud není 3, jen "vrať se, až to dokončíš"; při megaTask == 3 → reakce na vzkaz pro daný megaIndex (3 různé texty) + tlačítko / poslední replika → GiveNextIslandCoords() (nebo u megaIndex == 2 → finále).
HUDCounter.RefreshStory() case 3: podle megaTask ukázat aktuální cíl ("Znič obranu ostrova" / "Najdi trezor a vyřeš zámek" / "Vrať se za námořníkem se vzkazem").
MegaIsland render

Beze změny — EnsureIslandTerrain už MegaIsland umí, minimapa/mapa fialově.

3. Ostrov 1 — detail

MegaIslandMarker.BuildFortress():

Děla: 2–3× HostileIslandCannon.Spawn(tile, "mega") na okrajových MegaIsland dlaždicích u vody (deterministicky). Klíč "mega" → clearedIslands.
Strážci: nový LandGuard.cs (primitiva jako sokův panáček). Pole hp, TakeHit(float), Update(): pokud je hráč (v lodi i pěšky) do vzdálenosti RANGE a "vidí" ho, každých RELOAD s vypálí CannonBall.Fire(..., Side.Enemy). Na smrt → řekne markeru. 2–3 kusy u trezoru.
Trezor: kamenná bedna + dveře (primitiva) uprostřed vedle obelisku.
6 tabulek s vodítky: ploché kameny s textem, rozeseté po ostrově (deterministicky). Text = krátká hádanka česky, dohromady dá 4-symbolový kód.
Vzkaz: malý objekt (svitek) uvnitř trezoru, aktivní až megaTask == 2.

Tok: přijedeš (storyStep 3, megaTask 0) → sejmeš děla + hlídkující loď z lodě → megaTask 1 → doplaješ, pěšky → čteš tabulky, luštíš, zadáš kód na trezoru → megaTask 2 → E na vzkaz → megaTask 3 → domů → dialog s námořníkem → GiveNextIslandCoords().

Puzzle — 3 varianty (rozhodnout při implementaci)
Kód z hádanek (doporučeno): ~6 tabulek, každá je nápověda k jednomu ze 4 symbolů kódu (2 jsou návnady). Zadání na trezoru = 4 pozice, cyklíš symboly (E), potvrdíš. Feedback "X ze 4 správně". Řešitelné, textově obhajitelné, zabere čas (velký ostrov + přemýšlení).
Sekvence aktivace: 4–5 ohňů, zapálit ve správném pořadí (z obelisku), špatně → reset. Jednodušší, ale kratší.
Kombinace z prostředí: kód = počet děl + směr stínu obelisku + datum na hrobu… Hezké, ale těžší udělat férové.
4. Přepad na moři

Nová statická třída StoryEvents (jen metody, žádný stav — stav v GameData): StoryEvents.CheckAmbush(GridManager grid) volaná z PlayerController.OnEnteredTile. Když storyStep == 2 && megaIndex >= 1 && !ambush1Done a hráč je do ~30 políček od poloviny úsečky (start ostrov → storyIslandX/Y) → PirateShip.Spawn ×2, CombatDirector.Instance.Toast(...), ambush1Done = true, grid.Save().

5. Ostrov 2 & 3 — náčrt (pozdější kousky)

Ostrov 2 (BuildWreckGraveyard): ship-ghost mini-boss (přesunout ship-ghost.fbx do Assets/Resources/, Resources.Load jako pirátské lodě). 3 kopací místa v mělčině kolem ostrova → DigRoutine-styl z lodě (reuse mega quest dig). Po 3 kusech → kód do podpalubí. Jiné hádanky, jiná tematika.

Ostrov 3 (BuildConfrontation): na příjezd spawn velké pirátské lodě jako boss (tuning HP). Po potopení → vylodění → RivalNpc.cs (jako StoryNpc, jiný vzhled) na ostrově. Finální dialog strom, storyDone = true, storyStep na finální hodnotu, odměna. Poslední replika u starého námořníka doma.

9. Rizika / kde neztloustnout
Nepřidávat nový TileType pro trezor/tabulky — jsou to jednorázové objekty jednoho ostrova, marker si je drží pozičně (enum se serializuje → append-only bolest).
MegaIslandMarker se snadno rozroste do dalšího God objektu — držet ho tenký, jednotlivé části (BuildFortress, puzzle, LandGuard) do vlastních metod/souborů.
Puzzle musí mít férový feedback ("X ze 4"), jinak je to hádání a u zkoušky se to blbě obhajuje.
Deterministické pozice (hash, ne Random za běhu) — jinak po loadu ostrov jinak.
